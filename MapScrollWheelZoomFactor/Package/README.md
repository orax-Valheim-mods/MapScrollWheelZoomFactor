# Installation

This mod is client-side only. You do not need to install it on the server.

## Using a mod manager (recommended)
You can install the mod using Vortex, R2ModMan or Gale.

## Manual
Install BepInExPack for Valheim. Copy the DLL file to `Steam\steamapps\common\Valheim\BepInEx\plugins\`

# Configuration

Configuration file is located at: `Valheim\BepInEx\config\orax.mapscrollwheelzoomfactor.cfg`
Game default: 2. Higher value = faster zoom in/out.
A game restart is required after a configuration change.
